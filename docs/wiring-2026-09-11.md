# Hosted SDK·CLI·MCP wiring verification — 2026-09-11

The workspace pins engine commit `791c7bc5fb1eb80d1dee052fc895a289a0d09e50`.
Client, CLI and MCP sources are installed together; the code-free `adaptorch`
meta-package remains outside that workspace to avoid replacing the private engine.

## Verified contracts

- Tenant credentials select `X-API-Key`; service credentials select Bearer auth.
- SDK submissions can send one `ProviderCredential`. CLI `run submit` reads the
  three documented `ADAPTORCH_PROVIDER*` variables. Neither path attaches the
  provider credential to request JSON, reads or cancellation.
- Actual FastAPI BYOK refusals retain their stable code/instructions, with both
  authentication secrets redacted from displayed errors.
- Artifact results accept legacy `items` and hosted `artifacts`. A storage path is
  not presented as a downloadable URL, known file size or checksum.
- SDK discovery, submission/idempotency, listing, detail, evidence, artifacts and
  cancellation are exercised against real local HTTP → FastAPI routing.
- The public MCP wrapper's nine remote-profile tools are exercised through the same
  HTTP server. Serving-only `auto` is distinct from the four engine algorithms;
  requested/selected mode fields survive output projection.

## Evidence

- Before the fix: new SDK tests had 18 failures; the old client rejected the actual
  artifact map and hid `byok_credentials_required` behind a generic HTTP 401.
  The CLI BYOK composition test also failed before its headers were wired.
- Fresh pinned environment: `uv sync --frozen --all-packages --extra dev --python 3.12`.
- `uv run --frozen ruff check packages`: exit 0.
- `uv run --frozen mypy`: exit 0, 26 source files.
- `uv run --frozen pytest -o addopts= -q`: **346 passed, zero skips**.
- Wheel/sdist builds passed for client, CLI, MCP and the meta-package.
- Public wheel inspection passed. The existing MCP in-process engine dependency is
  still an explicit warning/exception; this change does not claim to remove it.

The integration test uses temporary tenants and storage. It replaces
`execute_run_async` with a queued-only test implementation, so no model work runs.
Cancellation preserves the backend's existing status representation rather than
inventing a new one. No production customer record, payment or credential is modified.

The source repository push and Railway deployment are separate from publishing
packages to PyPI. These changes are available through the source-install instructions;
this operation does not publish replacement PyPI artifacts.
